#Projeto - Controle de nível de água
💻 Este projeto consiste em um sistema de monitoramento de um reservatório de água. O programa simula cinco níveis de água e exibe mensagens de alerta co cores diferentes para cada nível utilizando a biblioteca colorama.

📌 O objetivo do programa é monitorar os níveis de água e alertar para o nível atual do reservatório.
